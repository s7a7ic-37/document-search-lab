    How the evaluation works

    Keyword search uses TF-IDF to give terms that are common in a document and rare in the library more weight. Semantic search compares the same text in a smaller topic space made with truncated SVD.

    Recall at 3 measures how many expected documents are in the first three results. Mean reciprocal rank (MRR) gives more weight to finding the first expected document near the top. Both numbers are averaged across the sample questions.

    Both models are fitted on the documents only and can miss words absent from those documents. This is a small synthetic example, so the scores describe these questions. The dashboard loads a report generated offline.
